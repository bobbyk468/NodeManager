TROUBLESHOOTING QUICK LINKS

Problem                     Solution
─────────────────────────   ─────────────────────────────────────────
Audio silent                Check mic in System Preferences
Dashboard won't load        curl http://localhost:5173/ then restart
Port 5173 in use            lsof -ti:5173 | xargs kill -9
Database locked             rm -f data/study_sessions.db.lock
Session crashed             pkill -f "npm run dev"; restart all
Participant won't answer     Mark NO-GO; document reason; reschedule

For more details, see STUDY_SESSION_SOP.md Part 7 (Troubleshooting)

DAILY OPERATIONS

MORNING:
  1. Print assignment sheet → identify today's participant
  2. Prepare consent forms (2 copies)
  3. Backup yesterday's data: tar -czf data/backups/...
  4. Verify systems ready: npm --version && python3 --version

AFTER EACH SESSION:
  1. Move audio/screen files to: data/recordings/$PARTICIPANT_ID/
  2. Run validation check
  3. Update assignment sheet status
  4. Save session JSON

END OF DAY:
  1. Generate daily report
  2. Backup all session data
  3. Check validation gate (every 5 sessions)

END OF WEEK:
  1. Generate weekly report
  2. Email status to PI
  3. Assess recruitment progress
